### 2. RRF 重复加分修复（问题44）

**修复前**：chunk 数量影响商品排名
```python
# 商品 A 有 3 个 chunk，商品 B 有 1 个 chunk
# → 商品 A 获得 3 倍加分，不公平
```

**修复后**：先聚合到商品级，再融合
```python
for results in results_list:
    # 先聚合到商品级
    product_scores = aggregate_chunks_to_products(results)
    sorted_products = sorted(product_scores.items(), ...)
    # 再进行 RRF 加分
    for rank, (product_id, _) in enumerate(sorted_products, start=1):
        rrf_score = 1.0 / (k + rank)
        scores[product_id] = scores.get(product_id, 0.0) + rrf_score
```

**测试结果**：两个商品分数差异 < 0.001，公平合理 ✅
