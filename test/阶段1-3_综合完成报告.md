## 📊 阶段3：接入业务与证据

### 核心成果

#### FlowStatus 枚举（7种终态）
```python
SUCCESS                 # 成功执行
WAITING_SLOT           # 缺少槽位
NO_RESULT              # 空查询（正常）
RETRYABLE_ERROR        # 可重试（如 503）
PERMANENT_ERROR        # 永久错误（如无权限）
UNSUPPORTED_FLOW       # 能力未开放
CONFIGURATION_ERROR    # 配置错误
```

#### 任务完成时机
- **旧**: 在 tool_dispatch 中根据 tool_result.ok 完成
- **新**: 在 Guard 检查后根据 should_complete_task() 判断
- **条件**: Guard PASS + FlowStatus SUCCESS + tool_result.ok + ready_for_response
