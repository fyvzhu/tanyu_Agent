```

   ↓
```

## 📊 阶段2：统一判定与任务语义

### 核心成果

#### 1. 等待槽位优先规则

**文档依据**: 第193-194行

**实现**: 在 `intent_parse_node` 中添加优先级链：
```
1. 检查取消请求 ✅
2. 检查 pending_intent_selection ✅
3. 检查 WAITING_SLOT（阶段2核心）✅
   - 不是明确新目标 → 尝试补槽
   - 补槽成功 → 继续任务
   - 补槽失败 → 走正常分类
4. 正常意图分类 ✅
```

#### 2. 智能槽位补填

**文档依据**: 第39行问题描述

**解决方案**:
- ❌ **旧**: "预算500，商品15970" → 取500（错误）
- ✅ **新**: 检测"预算"关键词 → 拒绝解析

- ❌ **旧**: "15970和39386" → 任取15970（错误）
- ✅ **新**: 检测多个编号 → 拒绝自动选择

**智能策略**:
1. 价格关键词检测（"元"、"预算"、"以内"）
2. 格式校验（商品4-6位，订单8位以上）
3. 多候选拒绝（让系统询问用户）

**位置**: `slot_check.py` 第87-102行

**原因**: 简单的"取第一个数字"逻辑导致误判，已由统一的 `_try_fill_missing_slots` 替代
