### 1. 建立固定的终态集合（FlowStatus）

**文件**: `customer-service-backend/customer_service/flows/models.py`

**新增枚举**（第25-48行）：
```python
class FlowStatus(str, Enum):
    """Flow 执行的固定终态集合"""
    SUCCESS = "success"                    # 成功执行，有业务结果
    WAITING_SLOT = "waiting_slot"          # 缺少必需槽位
    NO_RESULT = "no_result"                # 成功但无业务结果（空查询）
    RETRYABLE_ERROR = "retryable_error"    # 可重试（如 Commerce 503）
    PERMANENT_ERROR = "permanent_error"    # 不可重试（如无权限）
    UNSUPPORTED_FLOW = "unsupported_flow"  # Flow 未注册/能力未开放
    CONFIGURATION_ERROR = "configuration_error"  # 工程配置错误
```

**解决的问题**（文档第74行）：
- ❌ **旧**: 缺 runtime 直接返回、Flow 未注册设置 None、异常只写字符串
- ✅ **新**: 每种情况都有明确的 FlowStatus，配合 ToolError 详细说明

### 3. 正确的任务完成时机

**文件**: `customer-service-backend/customer_service/graph/nodes/hallucination_guard.py`

**新增函数**: `should_complete_task()`（第307-358行）

**完成条件**（文档第52行）：
1. ✅ Guard 状态为 PASS（不是 FALLBACK 或 RETRY）
2. ✅ FlowResult 状态为 SUCCESS
3. ✅ tool_result.ok = True
4. ✅ ready_for_response = True

**不完成的情况**：
- WAITING_SLOT: 等待补槽
- CLARIFY: 需要澄清
- Tool 错误: 失败或可重试
- Guard 拦截: FALLBACK 或 RETRY

**调用时机**（第307-313行）：
```python
# Guard 检查后，判断是否完成任务
if should_complete_task(state):
    logger.info(f"[{turn_id}] 🎯 本轮任务成功且 Guard 通过，完成当前任务")
    state = TaskContextManager.complete_current(state, turn_id)
else:
    logger.info(f"[{turn_id}] ⏸️ 本轮未完成任务")
```

### 4. 更新 response_gen.py 处理新状态

**文件**: `customer-service-backend/customer_service/graph/nodes/response_gen.py`

**新增处理**（第131-207行）：

| FlowStatus | 用户响应 | fallback_used |
|-----------|----------|---------------|
| CONFIGURATION_ERROR | "系统配置出现问题" | True |
| UNSUPPORTED_FLOW | "该功能暂未开放" | True |
| RETRYABLE_ERROR | "遇到问题，稍后再试" | True |
| PERMANENT_ERROR | "无法处理请求" | True |
| WAITING_SLOT | "请提供更多信息" | False |
| NO_RESULT | "没有找到相关信息" | False |
| SUCCESS | 正常业务响应 | False |

**区分能力**：
- **配置错误 vs 下游故障**: 不同的错误码和响应
- **可重试 vs 永久错误**: retryable 标志明确
- **空结果 vs 失败**: NO_RESULT 不是错误，PERMANENT_ERROR 才是
